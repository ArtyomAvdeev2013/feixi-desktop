# Feixi Desktop 💬

Десктопная версия мессенджера и социальной сети Feixi — общайтесь в личных
и групповых чатах, отправляйте и смотрите фото и видео, читайте книги, смотрите календарь,
изучите карту и погоду, переводите слова, создавайте объявления, слушайте музыку, играйте, и это всё
не открывая браузер.

## Возможности
- Личные и групповые чаты
- Отправка фото, видео и файлов
- Публикации и блоги — как в социальной сети
- Напоминания и таймеры для удобного планирования
- Сервисы Feixi/РуСайта (для всего)

## Сборка
1. Клонируйте репозиторий:
   git clone https://github.com/ArtyomAvdeev2013/feixi-desktop.git
2. Соберите проект (шаги зависят от стека — см. ниже).
3. Сборка и релизы настраиваются через GitHub Actions
   (.github/workflows/build.yml).

## Структура проекта
- `.github/workflows/` — автоматическая сборка
- `icon.ico` — иконка приложения
